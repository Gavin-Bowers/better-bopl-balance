# Better Bopl Balance
This mod makes various balance changes to improve bopl battle, based on the preferences of myself and my friend group. Abilities are buffed, nerfed, and reworked as appropriate.

## Credit
Created by Gavin Bowers, with much help from Claude Code

## Contents
* Beam Rework - Beam can be aimed rapidly while charging but no longer pushes platforms and black holes
* Tesla Coil & Engine Buff - Placement animation time is halved
* Single Use Revive - Revival now replaces itself with a random ability (other than itself) when used

## Ideas for future features
* Quicker throw animations
* Tesla coil turns off if relative speed between the coils is too high
* Time stop rework - time stop is immediate but you can't use abilities during it (and for a time after?). It becomes an escape/movement tool
* Grappled players are freed after a certain amount of time
* Better random - doesn't give loadouts that can't kill (may be infeasible if each random operates independently - solution could be random weapon, random utility, etc.) 
* Get rid of minimium platform size / change how platforms shrink to be more regular
* Make grenade explode on mines - also make mines explode when hit with an attack before they're armed
* Placeable mirror ability that reflects projectiles and beams. Can be used to grow, shrink, clone, and blink yourself in space maps.
* Lighter sword for better sword throw and sword move. Also less sword end-lag
* Ability cooldowns progress when using move, faster move speed
